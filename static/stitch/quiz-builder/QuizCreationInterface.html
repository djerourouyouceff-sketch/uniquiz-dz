الترجمة بالعربية (اختياري للطلبة):

محرك حراري عكوس يعمل وفق دورة كارنو بين مصدر ساخن Th = 800 K ومصدر بارد Tc = 300 K. ما هي القيمة الدقيقة للمردود الحراري النظري (η) لهذا المحرك؟

Cochez le bouton radio vert pour la réponse correcte
A. EXACTE (100%)
B. 0 pt
C. 0 pt
D. 0 pt
info Explication pédagogique insérée dans le rapport étudiant

Selon le théorème de Carnot, le rendement d'un cycle réversible dépend uniquement des températures absolues en Kelvin: η = 1 - (Tc / Th) = 1 - (300 / 800) = 0.625 soit 62.5%. Toute réponse calculée en °C entraîne une erreur de conversion.
